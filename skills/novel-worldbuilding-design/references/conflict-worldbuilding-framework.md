# Conflict Worldbuilding Framework

Use this reference when the world needs stronger plot pressure or the user only provided loose ideas.

## Conflict-first lenses

Design from these questions before naming places:

1. What scarce thing decides survival, dignity, status, or power?
2. Who monopolizes it legally?
3. Who sells it illegally?
4. Who interprets the rules around it?
5. Who does the dirty work that keeps the system running?
6. Who benefits from the myth that the system is fair?
7. What loophole lets the protagonist disrupt the order?
8. What does disruption cost innocent people?

## Useful opposition axes

- Class: nobles vs commoners, inner sect vs outer sect, registered citizens vs unregistered people.
- Resource: spiritual energy, land, medicine, data, relics, dragon veins, official permits, exam quotas.
- Legitimacy: imperial law vs sect law, orthodox doctrine vs practical survival, public justice vs private revenge.
- Knowledge: official history vs erased truth, public cultivation manuals vs forbidden techniques.
- Geography: capital vs borderland, safe city vs wasteland, inner domain vs outer domain.
- Bloodline or identity: chosen lineage vs mixed blood, native vs outsider, human vs nonhuman, old clan vs new money.
- Technology or method: orthodox path vs industrial path, ritual path vs scientific path, individual talent vs collective machinery.

## Organization template

For each faction, sect, institution, guild, academy, clan, company, church, or bureau:

- Public face: what they claim to protect.
- Real interest: what they cannot afford to lose.
- Monopoly: resource, legitimacy, violence, knowledge, logistics, finance, medicine, exams, archives, prophecy.
- Internal split: hawks vs moderates, old guard vs reformers, heirs vs outsiders, idealists vs profiteers.
- Leverage over protagonist: debt, identity, family, license, hostage, secret, needed resource.
- Leverage protagonist has over them: talent, loophole, forbidden knowledge, public opinion, rare resource, rival patron.
- Repeatable scene use: trial, auction, examination, mission board, border inspection, banquet, tribunal, tournament, raid, negotiation.

## Map template

Prioritize places that create repeatable scenes:

- Newbie pressure zone: where the protagonist first suffers the rules.
- Public ranking zone: arena, exam hall, court, leaderboard, evaluation office.
- Transaction zone: black market, auction house, guild hall, broker street.
- Power center: palace, inner sect, council tower, corporate headquarters.
- Production zone: mines, farms, labs, spirit fields, workshops, data centers.
- Boundary zone: frontier, pass, dock, wall, checkpoint, border city.
- Forbidden zone: ruin, sealed cave, abandoned city, old battlefield, restricted archive.
- Truth zone: ancestral hall, memory vault, hidden library, god corpse, buried server.

## Power system stress test

A power system is useful when it creates decisions, not when it only ranks strength.

- Each level should create a new social permission or restriction.
- Advancement should require scarce inputs, public certification, dangerous trials, moral compromise, or political sponsorship.
- Failure should have visible costs: injury, debt, corruption, loss of license, public disgrace, dependence on a faction.
- The protagonist's cheat should break one bottleneck while creating a new enemy or exposure risk.

## Web novel payoff loops

Common repeatable loops:

- Humiliation -> rule discovery -> counterattack -> public reversal -> bigger enemy notices.
- Scarcity -> risky deal -> hidden gain -> exposed value -> pursuit.
- Examination -> unfair standard -> loophole win -> rank jump -> institutional backlash.
- Mission -> local injustice -> resource clue -> enemy faction -> staged victory.
- Secret identity -> partial reveal -> benefit -> suspicion -> forced escalation.

Tie each loop to the world's rules so the payoff feels earned.
