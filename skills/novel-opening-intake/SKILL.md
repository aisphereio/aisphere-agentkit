# 小说开题收集 Skill

目标：把用户零散、模糊、还没想清楚的小说想法，整理成后续 Agent 可以复用的开题 brief。重点不是让用户填完整档案，而是用尽量少的用户负担，捕捉会影响后续写法的关键偏好。

## 核心策略

- 少填字，多选择。优先用单选、多选、比例、默认值和可选补充。
- 必填项控制在 4-6 个以内：频道/读者方向、主角模式、核心题材、商业元素、核心爽感。
- 其余信息允许 AI 补草案：金手指、冲突轴、元素比例、主角身份、初始压力、一句话卖点都可以由模型先猜一版。
- 表单必须支持 AI 辅助填写：调用 `request_user_form` 时带上 `assist_label` 和 `assist_prompt`。
- 用户点 AI 辅助后，如果收到 `kind: user_form_assist_request`，请基于 `partial_values` 生成 `initial_values`，再次调用 `request_user_form` 让用户确认。
- 不要直接进入正文写作；除非用户明确要求，否则只产出结构化开题 brief。

## 推荐表单结构

调用 `request_user_form` 时，建议使用如下字段思路。字段可以很多，但必填要少。

必填字段：

- `channel`：男频、女频、无CP、双男主、轻小说、出版向、暂不确定
- `protagonist_mode`：单男主、单女主、双主角、多男主群像、多女主群像、团队群像、幕后流、反派主角
- `core_genres`：多选，包含玄幻、修仙/仙侠、都市、校园、科幻、末世、历史/架空、悬疑推理、恐怖、灵异、游戏电竞、轻小说、无限流、奇幻、西幻、克苏鲁、赛博朋克、年代文、娱乐圈
- `commercial_elements`：多选，包含系统、直播、聊天群、模拟器、重生、穿越、异能、御兽、种田、经营、基建、升级、打脸、复仇、真假少爷/千金、豪门、娱乐圈、校园、考试/学院、门派宗门、家族、官场、商战、诡异规则、怪谈、克苏鲁、无限副本、末世求生、机甲、星际、电竞、游戏面板、鉴宝、美食、医疗、破案、盗墓、幕后黑手
- `desired_payoffs`：多选，包含升级变强、打脸逆袭、扮猪吃虎、智斗布局、权谋夺权、经营扩张、探索揭秘、恐怖压迫、规则破解、情绪拉扯、团宠治愈、热血战斗、财富自由、身份揭露、复仇清算

可选字段：

- `relationship_mode`：无CP、单女主、单男主、双男主、双女主、多女主、多男主、暧昧拉扯、事业线为主
- `conflict_axis`：多选，阶层压迫、资源垄断、身份歧视、门派/机构垄断、家族控制、历史真相、世界规则骗局、阵营战争、情感伦理、信仰冲突、科技/超凡失控
- `tone_style`：爽快强节奏、轻松搞笑、热血燃、黑暗压迫、悬疑烧脑、群像厚重、甜爽、疯批拉扯、克制现实、沙雕脑洞
- `title_idea`：书名，可空
- `one_sentence_hook`：一句话卖点，可空
- `protagonist_seed`：主角身份和初始处境，可空
- `golden_finger_seed`：金手指或核心设定，可空
- `avoid_elements`：虐主、绿帽、悲剧结局、过度黑暗、降智配角、强行误会、后宫、感情线、恐怖、血腥、现实政治、低俗擦边、其他
- `free_notes`：自由补充
- `ratio_combat`、`ratio_growth`、`ratio_strategy`、`ratio_romance`、`ratio_management`、`ratio_horror`、`ratio_daily`：0-5 的比例滑块，默认 2 或 3

## AI 辅助填写规则

当用户点击“AI 帮我填一版”后：

1. 不要直接终止流程。
2. 根据用户已选项判断商业方向，例如“都市 + 系统 + 直播 + 打脸”可以补成强节奏爽文；“灵异 + 规则怪谈 + 聊天群”可以补成悬疑恐怖升级流。
3. 补全时必须让元素互相咬合：题材、金手指、冲突轴、主角身份、爽点循环要能互相制造剧情。
4. 再次调用 `request_user_form`，把补好的内容放入 `initial_values`，让用户确认或修改。

## 输出 Brief

用户提交表单后，输出并可保存 `opening_intake_brief.md`：

1. 已确认事实
2. AI 推断补充
3. 项目定位：频道、读者预期、题材组合、主角模式、关系模式
4. 商业元素池：主元素、辅助元素、谨慎使用元素
5. 核心爽点循环：压力 -> 行动 -> 反转 -> 收益 -> 更大压力
6. 主角入口：身份、初始困境、第一目标
7. 金手指/核心设定方向：能力、限制、代价、如何改变秩序
8. 冲突轴：阶层、资源、机构、身份、情感或真相
9. 元素比例：战斗、升级、智斗、感情、经营、恐怖、日常
10. 禁忌和边界
11. 仍需确认的问题，每个问题给 2-4 个推荐选项
