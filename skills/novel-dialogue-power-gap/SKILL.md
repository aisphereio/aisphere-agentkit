# 权力差对白法

## 适用场景

适合任何存在权力不对等、资源不对等、身份不对等、信息不对等的对话场景。这个 Skill 的目标不是解释“谁地位高”，而是让读者从对白长度、回应速度、行动服从、评价权和旁观者反应中自然看出权力差。

常见可用场景：

- 上位者第一次登场，需要迅速建立压迫感。
- 主角被误判、被压制，但场面里存在隐藏权力或隐藏筹码。
- 老板/员工、师父/徒弟、族长/晚辈、上司/下属、掌门/弟子、官员/平民、资源持有者/求助者等关系。
- 多人场景中，需要让读者一眼看清谁能命令、谁能评价、谁必须解释。

## 不适用场景

- 双方关系平等，重点是默契、亲密、玩笑或情感交流。
- 需要故意隐藏权力关系的潜伏、卧底、试探场。
- 角色处在失控爆发状态，语言秩序已经崩掉。
- 对话目的主要是交代复杂设定，而不是展示关系压迫。
- 需要让弱势方主动抢占上风的反打收束段，除非你是在写“权力转移”。

## 核心原理

权力差不是靠旁白标签建立的，而是靠“不对称”建立的：上位者拥有更短的表达、更慢的反应、更少的解释义务；下位者承担更长的回应、更快的动作、更重的解释压力。谁能命令、谁能沉默、谁能评价别人，谁就占据场面上位。旁观者的安静、改口、退让、等待，也能帮助读者确认权力秩序。

## 执行步骤

1. **标定权力来源**：先判断上位者为什么有压迫力。来源可以是身份、资源、武力、资历、信息、评价权、处罚权或场面控制权。
2. **分配语言长度**：上位者尽量短句、半句、单字、停顿；下位者使用完整句、解释句、请示句、补救句。
3. **制造回应速度差**：上位者可以慢、可以停、可以不解释；下位者要快，最好在说话前已经开始行动。
4. **放入命令权动作**：让上位者不用完整说明，下位者也能理解并执行。权力感来自“他只说一点，对方就补全全部”。
5. **放入评价权动作**：上位者用一句轻描淡写的评价确认关系，例如认可、否定、纠正、提醒、放过。评价越随意，权力越稳。
6. **用旁观者校准场面**：旁观者可以沉默、退半步、改称呼、看向上位者、等待指令。不要解释权力差，让反应替你说明。
7. **收束为秩序变化**：对话结束时，场面里至少有一个人改变了姿态、称呼、站位、语气、行动优先级，证明权力差已经生效。

## 示例模板

```text
【场景】公开资源分配场。资源持有者坐在主位，被评价者站在众人面前，旁观者等待结果。

资源持有者没有抬头，只说：“账。”

被评价者立刻把准备好的记录递上去，声音比刚才低了一截：“都在这里，缺口我已经补上，明早之前能交齐。”

旁观者原本想插话，听见“补上”两个字，又把话咽了回去。

资源持有者翻过一页，停了片刻：“还算知道轻重。”

被评价者这才松开攥紧的手，低声道：“我记下了。”
```

这个模板保留的是结构，不是题材：短命令、快速补全、旁观者退让、轻评价、秩序确认。把“账”换成任务、剑、合同、名单、药方、令牌、项目方案，都可以成立。

## 失败模式

| 失败模式 | 表现 | 修正方式 |
|---|---|---|
| 上位者解释太多 | 上位者把命令、原因、背景全说完，像客服说明 | 删掉解释，只保留关键词、停顿和评价 |
| 下位者太硬 | 下位者没有解释义务，也不执行，关系变成平等冲突 | 增加补救、请示、立即行动或姿态变化 |
| 只有身份没有动作 | 旁白说某人地位高，但对白没有体现 | 加入命令权、沉默权、评价权或旁观者退让 |
| 所有人说话长度一样 | 对话节奏均匀，层级感消失 | 上位者短，下位者长，中间层观察后再说 |
| 旁观者反应缺失 | 读者只能靠两个人互怼判断关系 | 加入旁观者的安静、改口、停手、退让 |
| 权力差过度夸张 | 下位者只会卑躬屈膝，人物变扁 | 让下位者保留专业能力，只在权力义务上处于下位 |

## 反过拟合规则

- 不绑定任何具体时代、行业、组织、家族、门派、公司或官职。
- 不绑定具体动作。关门、递账、倒茶、拔剑、交方案、递名单都只是可替换动作。
- 不绑定具体语气。下位者可以恭敬、克制、害怕、不服、圆滑，但必须承担回应和行动压力。
- 不把“上位者短句”机械化成所有句子都只有一个字。关键是解释义务少，而不是字数表演。
- 不把“权力差”写成单纯羞辱。真正有效的是秩序控制、评价资格和行动服从。

保留的抽象结构是：

```text
上位者少说或不解释 → 下位者快速补全并行动 → 旁观者反应确认秩序 → 上位者轻评价完成权力确认
```

## 验收标准

写完后检查：

- [ ] 读者不看身份介绍，也能判断谁拥有场面控制权。
- [ ] 上位者至少拥有命令权、评价权、沉默权中的一种。
- [ ] 下位者承担了更明显的解释、补救、请示或行动压力。
- [ ] 对话长度或回应速度存在可感知的不对称。
- [ ] 旁观者反应帮助确认权力秩序，而不是只当背景板。
- [ ] 结尾出现了称呼、姿态、站位、行动优先级或情绪状态的变化。
- [ ] 正文没有绑定任何源书、章节、角色、地点、组织或项目痕迹。
